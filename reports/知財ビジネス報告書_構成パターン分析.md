# 知財ビジネス報告書の構成パターン分析

知財金融ポータルサイトに掲載されている「知財ビジネス報告書」全32件を読み、どのような展開で書かれているかを類型化し、パターンごとの記載項目を整理したもの。

- 調査日：2026年11月5日（この時点の掲載分）
- 対象：[知財ビジネス報告書を探す](https://chizai-kinyu.go.jp/cases/) に掲載の全32件（令和6年度 8件・令和7年度 24件）と、令和7年度の要約版 24件
- 方法：各PDFの目次、各章の扉ページ、本文の見出しを読んで章立てと記載項目を抽出した。次に、特許庁が示す「基本構成」14項目と照合し、将来像（To-Be）がどの章まで書かれているかで分類した
- 判定の前提：公開版では中身が空欄（非公開）になっているページがあるため、章が設けられているかどうかで判定した

---

## 1. 結論

- **骨格は全件共通**：全32件が、特許庁の基本構成14項目（6章）に沿って書かれている。
- **違いは将来像の深さ**：将来像のうち任意とされている定量パート（項目10〜14）をどこまで書くかで、3つの型に分かれる。
  - A 方向性提示型：15件
  - B 戦略展開型：8件
  - C 計画数値化型：9件
- **融資の判断材料はC型に集まる**：年度別の計画や資金計画まで示すのはC型だけ。ただし公開版では、数値のページが非公開になっていることが多い。
- **令和7年度で様式が統一**：令和6年度は独自の章立てが多い。令和7年度はほぼ全件が基本構成の章名を使い、要約版も共通様式になっている。

## 2. 共通の骨格：基本構成14項目

出典：特許庁「[令和7年度 知財金融公募説明会資料](https://chizai-kinyu.go.jp/cms/wp-content/uploads/R7_知財金融公募説明会資料_公開用-1.pdf)」p.8「今年度知財ビジネス報告書の基本構成」

| | 6 | 現状の課題 | 現状 |
| 第4章 知財を活用した経営戦略策定に向けて（To-Be） | 7 | マーケットイン型での課題解決の方向性、事業目標 | 将来像・**定性（必須）** |

## 3. 3つの展開パターン

| 型 | 将来像の到達点 | 到達する章 | 件数（R7・R6） |
|---|---|---|---|
| **A 方向性提示型** | 項目7〜9で終わる | 第1〜4章 | 15件（11・4） |
| **B 戦略展開型** | 項目10〜13の個別戦略まで書く | 第1〜5章 | 8件（6・2） |
| **C 計画数値化型** | 項目14の数値計画まで書く | 第1〜6章 | 9件（7・2） |

### A 方向性提示型（15件）

**展開の流れ**：エグゼクティブサマリ → 企業概要 → 事業の核となる知的財産 → 現状のビジネス状況 → 知財を活用した経営戦略策定に向けて（ここで終わる）

**記載項目**
- **企業概要**：事業概要・経営方針、売上推移、製品事例、工程、保有設備
- **知財**：事業への貢献内容、保有知財（特許・商標）の分析・評価、ノウハウ・技能・顧客網などの無形資産
- **ビジネス状況**：3C、SWOT（一部はクロスSWOT）、現状の事業課題
- **将来像**：
  - 項目7 課題解決の方向性・事業目標：課題と方向性の対照表。開発・生産・知財・マーケティング・営業など機能別に分ける例が多い
  - 項目8 必要な経営戦略リスト：「方向性／必要な戦略／検討のポイント」の3列の表で整理する
  - 項目9 ビジネスモデル：ビジネスモデルキャンバス（南信州菓子工房は経営デザインシートで代用）
- **付け加えられる例**：付録のアクションプラン案（担当・期間・KPI）。内外機工、高崎保安機材など

**特徴**：必須範囲で完結する。知財の打ち手は「ノウハウの形式知化」「営業秘密の管理」「商標・ロゴの統一」など、方向性の段階にとどまる。令和6年度の虎彦・伊丹電機工業は、将来像が1〜2ページしかない。

**該当**
- 令和7年度：内外機工、トップ、里源、wead、高崎保安機材、PuREC、サンナノテクノロジー、成光精密、中村工業、セイコーウェーブ、南信州菓子工房
- 令和6年度：虎彦、伊丹電機工業、ナカムラマジック、タカモリ

### B 戦略展開型（8件）

**展開の流れ**：Aの流れ → 「知財を活用した経営戦略」の章（またはそれに当たる章）

**Aに加わる項目（基本構成の10〜13）**
- **知財戦略**：
  - 権利化方針・標準化・共同出願・部品ブランド化（日本特殊光学樹脂）
  - オープン／クローズ戦略（渋谷光学）
  - 新規の特許出願と商標・意匠の組み合わせ（サン・セロ）
  - 知財基盤の強化策（築地にっしん太助）
- **販売・市場開拓戦略**：
  - 特許マップで顧客を選び、段階的に参入（フジメカニック）
  - 承認までの工程表とアクションプラン（オキシキャリア）
- **財務・事業構造**：
  - 10年後の事業ポートフォリオと財務体質の強化（築地にっしん太助）
  - ブランド価値向上による経営への影響（羅臼海産）
  - 財務分析と中期事業計画策定の提言（サン・セロ）

**特徴**：個別の戦略は章を立てて具体化するが、年度別の数値計画は置かない。羅臼海産は、将来像を「イントロダクション」と「詳細版」の2段で構成している。

**該当**
- 令和7年度：日本特殊光学樹脂、フジメカニック、築地にっしん太助、オキシキャリア、渋谷光学、アルコ（戦略章の本文は非公開）
- 令和6年度：羅臼海産、サン・セロ

### C 計画数値化型（9件）

**展開の流れ**：A・Bの流れ → 事業（実行）計画

**加わる項目（基本構成の13〜14が中心）**
- **年度別の数値計画**：3〜8年分の売上・損益・収支（宇治園製茶は2026〜2033年、マルエーはR8〜R12年、まつえペイントは損益・収支計画）
- **キャッシュフロー予測とシナリオ**：現状維持／ノーマル／ベストの3シナリオ（ラ・レトリなかしべつ）、ベスト／現状維持の2シナリオ（ナカムラマジックR7）
- **投資と回収**：設備投資の回収計画、特許ロイヤリティの試算、助成金が後払いのため生じるつなぎ資金の必要性（シスコム）、トレーサビリティ設備の投資計画（オーエーセンター）
- **財務戦略**：資金の使い道、必要額、調達方法、時期
- **短期（3年）・中長期（5年）の戦略と5年後の姿**（マルエー）
- **リスク評価・今後検討すべき論点**（ナベル、ナカムラマジックR7、シスコム）

**特徴**：
- 金融機関の融資判断に直結する「いつ・いくら必要か」まで示す。
- オーエーセンターは14項目すべてを埋めており、各ページに「To-Be(定性)」「To-Be(定量)」と表示している。特許庁の説明会資料でも見本として引用されている。
- 公開版では数値のページが空欄になっていることが多い（ナカムラマジックR7、ナベル、Nebraska、ラ・レトリなかしべつ、マルエーの財務戦略）。
- ナカムラマジックR7・Nebraska・ナベルは「策定に向けて」の章を置かず、方向性や戦略リストを「知財を活用した経営戦略」の章にまとめている。

**該当**
- 令和7年度：まつえペイント、宇治園製茶、マルエー、ナカムラマジック、Nebraska、ラ・レトリなかしべつ、ナベル
- 令和6年度：オーエーセンター、シスコム

## 4. パターンをまたぐ構成上の違い

| 観点 | 内容 |
|---|---|
| 冒頭の置き方 | 32件中26件がエグゼクティブサマリで始まる。全体ストーリーを置く例（ナカムラマジックR7、ラ・レトリなかしべつ）、ヒアリング経過を置く例（シスコム）、「はじめに」で知財の捉え方を定義する例（羅臼海産）もある。エグゼクティブサマリがないのは成光精密、渋谷光学、ナベル、タカモリ、ナカムラマジック（R6・R7） |
| 章の順序 | 標準は「企業概要 → 知財 → ビジネス状況」。ビジネス状況を知財より先に置く例が4件（里源、PuREC、セイコーウェーブ、虎彦） |
| 事業・製品別の分析 | 分析を事業や製品ごとに繰り返す例（渋谷光学、ナカムラマジックR6、PuREC）と、対象事業を絞る例（羅臼海産、アルコ）。計5件 |
| 年度による違い | 令和6年度は独自の章立てが多い。例：タカモリは番号付き4章の文章中心、サン・セロは「知財戦略策定に向けた分析とご提案」の章を独立、伊丹電機工業は他社特許と比べる「知財分析」の章。令和7年度はほぼ全件が基本構成の章名を使う |

## 6. 要約版と事例ページの様式

### 令和7年度 要約版（2ページ、24件とも同じ様式）

| ページ | 欄 |
|---|---|
| 1ページ目 | 企業名・金融機関名／知財・事業の概要と報告書作成の目的（業種・知財の種類）／記載概要：過去〜現在（As-Is）＝知的財産（強み・壁）をいかに生み出し、事業に貢献してきたか／記載概要：現在〜将来（To-Be）＝将来像の実現に向けた課題と解決の方向性（事業構想）、実行計画／作成を支援した機関名・氏名 |
| 2ページ目 | 金融機関からの評価結果：報告書を通じて認識した強み（改めて認識した点／新たに認識した点）、認識した課題（同）、将来のビジネス展開に向けて金融機関としてサポートできる点／企業からのコメント：新たな気づき、報告書の活用方法 |

### 令和6年度 事例ページ（Web）

業種・知財の種類／知財および事業概要／知財ビジネス報告書の記載概要／金融機関からの評価概要／報告書PDFへのリンク

令和7年度の事例ページは、本体と要約版のPDFへのリンクだけになった。概要と金融機関の評価は要約版に移っている。

- 報告書の著作権は特許庁に帰属する。公開された報告書を使う場合は、特許庁ウェブサイト（知財金融ポータルサイト）からの引用である旨を示す必要がある（各報告書の末尾の注記による）。
